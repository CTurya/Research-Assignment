# Foundations of Data Analytics, Data Science & Business Analytics Terminology

## Overview

This repository provides an introduction to the core concepts, principles, and terminology used in **Data Analytics**, **Data Science**, and **Business Analytics**. It is designed for beginners, students, and professionals seeking a foundational understanding of how data is collected, analyzed, and transformed into actionable insights for decision-making.

---

## Learning Objectives

After completing this material, you should be able to:

* Understand the fundamentals of Data Analytics, Data Science, and Business Analytics.
* Differentiate between descriptive, diagnostic, predictive, and prescriptive analytics.
* Recognize the data analytics lifecycle.
* Identify the roles and responsibilities of data professionals.
* Understand common business analytics terminology.
* Explain how organizations use data to solve business problems and improve decision-making.

### 6. Business Analytics Terminology

Common terms include:

| Term                            | Definition                                                                      |
| ------------------------------- | ------------------------------------------------------------------------------- |
| Data                            | Raw facts and figures collected from various sources.                           |
| Information                     | Processed data that provides meaning.                                           |
| Dataset                         | A structured collection of related data.                                        |
| Database                        | An organized system for storing and managing data.                              |
| KPI (Key Performance Indicator) | A measurable value used to evaluate business performance.                       |
| Dashboard                       | A visual display of key metrics and performance indicators.                     |
| Metric                          | A quantifiable measure used to track performance.                               |
| ETL                             | Extract, Transform, Load process used for preparing data.                       |
| Data Warehouse                  | A centralized repository for historical business data.                          |
| Big Data                        | Extremely large and complex datasets requiring advanced tools.                  |
| Machine Learning                | Algorithms that enable computers to learn from data.                            |
| Artificial Intelligence (AI)    | Technology that enables machines to perform tasks requiring human intelligence. |
| Data Mining                     | Discovering hidden patterns and relationships within large datasets.            |
| Visualization                   | Presenting data graphically using charts and dashboards.                        |
| Forecasting                     | Predicting future outcomes using historical data.                               |
| Regression                      | A statistical method used to predict continuous values.                         |
| Classification                  | Assigning data into predefined categories.                                      |
| Correlation                     | A measure indicating the relationship between variables.                        |
| Outlier                         | A data point that differs significantly from the rest of the data.              |
| Data Quality                    | The accuracy, completeness, consistency, and reliability of data.               |

## Key Differences

| Data Analytics                       | Data Science                                          | Business Analytics                                 |
| ------------------------------------ | ----------------------------------------------------- | -------------------------------------------------- |
| Focuses on analyzing historical data | Combines analytics, programming, and machine learning | Focuses on improving business decisions            |
| Uses statistical methods             | Uses advanced algorithms and predictive models        | Uses business knowledge with analytical techniques |
| Answers "What happened?"             | Answers "What will happen?"                           | Answers "What should the business do?"             |
